# CodeAlpha Python Programming Internship Projects

Recreated source bundle for the three CodeAlpha tasks Sudharsan M S identified as completed:

1. **Hangman Game** - five predefined words, one-letter guesses, and a six-incorrect-guess limit.
2. **Stock Portfolio Tracker** - manual sample prices, quantity input, subtotal and total calculations, and optional CSV export.
3. **Basic Chatbot** - simple phrase matching with predefined replies and a `bye` exit.

These are clean reimplementations based on the internship task sheet, not a recovery of the deleted GitHub repository or its original commit history. The exact original source code and commit metadata were not available.

## Requirements

- Python 3.10 or newer
- No third-party packages

## Run the projects

From the repository root, run one command at a time:

```bash
python TASK1_Hangman/hangman_game.py
python TASK2_Stock_Portfolio_Tracker/stock_portfolio_tracker.py
python TASK4_Basic_Chatbot/basic_chatbot.py
```

The portfolio tracker uses hardcoded example prices. It does not retrieve live market prices or provide investment advice. If CSV export is selected, it writes `portfolio_summary.csv` to the current working directory.
